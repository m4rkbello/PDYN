1. INSTALL THE PROJECT FILE CREATOR OF REACT NATIVE
->npx @react-native-community/cli init PANGAN SA FOLDER

2.INSTALL FIREBASE CONNECTION
->npm install @react-native-firebase/app @react-native-firebase/auth

3. INSTALL THIS IMPORANT NAVIGATION, REACT NATIVE SCREENS AND MORE
->npm install @react-navigation/native @react-navigation/native-stack react-native-screens react-native-safe-area-context react-native-gesture-handler react-native-reanimated

4. INSTALL NATIVE WIND AND TAILWIND
->npm install nativewind
->npm install --save-dev tailwindcss
->npx tailwindcss init

5. INSTALL DRAWERS AS SIDEBAR 
->npm install @react-navigation/drawer react-native-gesture-handler react-native-reanimated react-native-safe-area-context react-native-screens

6. INSTALL REACT NATIVE AND FIREBASE APP
->npm install @react-native-firebase/app
->npm install @react-native-firebase/firestore

7.FILE APP ASSEMBLE 
# Remove node_modules and clean
rm -rf node_modules
rm -rf android/app/build
rm -rf android/build
rm -rf android/.cxx
rm -rf android/app/.cxx
rm -rf android/app/build/generated
rm -rf .gradle

# Clear caches
npm cache clean --force
watchman watch-del-all

# Reinstall
npm install
cd android && ./gradlew clean
cd ..

# Rebuild the project
npx react-native run-android
